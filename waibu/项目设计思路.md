# 智慧校园网络安全异常检测系统 — 项目设计思路

本项目面向高校校园网络安全场景，旨在解决传统静态规则告警噪音高、缺乏实时可视化、无法识别复合攻击链等问题。系统整体采用前后端分离架构：后端基于 Spring Boot 3.2 + PostgreSQL 提供 REST API 与 WebSocket 实时推送，前端基于 React 18 + ECharts 实现交互式安全态势大屏，通过 Docker Compose 三服务编排（数据库 + 后端 + 前端）实现一键部署。

在检测能力上，系统设计了规则引擎与算法引擎双轨并行的方案。规则引擎负责检测 DDoS、端口扫描、蠕虫传播等 6 类已知威胁，所有阈值均基于历史流量动态计算，避免硬编码阈值带来的误报；算法引擎则包含四个创新模块：EWMA-EAD 融合流量基线与协议熵识别隐性异常，MDTCE 通过告警关联图与 Cyber Kill Chain 映射将离散事件聚合为完整攻击链，NBF-RS 为每个 IP 构建 7 维行为指纹进行风险评分，TPM-PA 基于线性回归趋势预测未来威胁，实现从"事后响应"向"主动预警"转变。

在数据与可视化设计上，系统引入时间基准锚点机制，所有时间窗口查询以数据库最新记录时间为准而非服务器时钟，确保历史导入的 PCAP 数据也能正常展示。前端设计了全景画像（实时指标 + 四级区域下钻）、安全态势（3D 地球攻击溯源）、微观流检索（CIDR/端口范围搜索）、单 IP 画像四个页面，通过 WebSocket 实现秒级指标推送，满足安全团队的实时监控需求。
