**讲解词**：

> 这是安全威胁感知中心。3D地球攻击溯源地图是我们的可视化亮点——采用纯前端Canvas内存纹理渲染，结合WebGL Bloom泛光特效和Jitter坐标抖动算法，同城市多条告警不会重叠。整个3D场景在浏览器端完成渲染，零服务器开销。

**步骤2 – 告警列表**（15秒）：
> 右侧是实时告警列表。支持按威胁类型——DDoS、端口扫描、慢速扫描、蠕虫传播、钓鱼攻击、数据外泄——按严重级别、IP地址、时间范围进行多维筛选。支持CSV一键导出取证。

>
> **NBF-RS**——7维行为指纹综合评分，量化IP综合风险。
>
> **TPM-PA**——Pearson跨信号相关+趋势预测，实现预防性告警。

## 四、录制注意事项

### 技术规格
| 项目 | 建议 |
|------|------|
| 分辨率 | 1920×1080（1080p） |
| 帧率 | 30fps |
| 编码 | H.264（x264），CRF 18–20 |
| 码率控制 | VBR，目标 4–8 Mbps（5分钟约150–300MB原始） |
| 最终压缩 | 用 HandBrake 或 FFmpeg 二压至 ≤100MB |
| 音频 | AAC 128kbps，单声道即可 |

### 文件大小控制
如果录制后超过100MB，用以下FFmpeg命令压缩：

```bash
ffmpeg -i input.mp4 -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 128k output.mp4
```

CRF值越大文件越小，从20开始试，直到满足100MB限制。

### 文件命名
```
T2601487—无敌暴龙战队—A19面向智慧校园的细粒度网络流量监控与安全态势感知系统—项目演示视频.mp4
```

### 录制Tips
1. **录制前确认两台服务器都在运行**：主站 + Linux打流端
2. **打开浏览器时保留地址栏1–2秒**，让评委看到 `8.146.228.64` 公网IP
3. **关闭所有无关程序**，避免弹窗/通知打断录制
4. **浏览器标签页只保留系统**，避免误切
5. **如果某段录错了**，不要停止，继续录完，后期剪辑替换即可
6. **录制两遍**，选更好的一版，或剪辑拼接两版最佳片段
7. **最终检查**：播放一遍确认画质清晰、音频正常、时长≤5分钟、大小≤100MB
