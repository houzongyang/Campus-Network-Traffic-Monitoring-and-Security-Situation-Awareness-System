# 开源代码与组件使用情况说明

**项目名称**：校园网络安全监控与威胁分析系统  
**团队**：苏州大学 无敌暴龙战队  
**文档版本**：v1.0  
**编写日期**：2026 年 4 月  

---

## 一、概述

本项目采用前后端分离架构，后端基于 Java 17 + Spring Boot 3.2.0，前端基于 React 18 + Vite 5。系统核心算法（EWMA-EAD、MDTCE、NBF-RS、TPM-PA）及 PCAP 报文解析器均为团队自主实现，其余功能性组件均使用经过 OSI 认证的主流开源软件。本文档对所有开源依赖的名称、版本、开源协议及具体用途进行说明。

## 五、自主研发代码说明

本项目以下核心模块**完全由团队自主实现**，不依赖任何第三方算法库：

### 5.1 PCAP 报文解析器（PcapImportService）

- **代码量**：约 807 行 Java
- **功能**：纯 Java 实现的二进制 PCAP 文件解析器，支持 Global Header 与 Packet Header 解析，兼容 Ethernet/Raw IP 链路层，支持 IPv4/IPv6 网络层，支持 TCP/UDP/ICMP 传输层协议提取，输出标准化 `NetworkFlow` 流记录
- **无第三方依赖**：未使用 jpcap、pcap4j 等任何第三方 PCAP 库

### 5.2 四大创新算法

#### 5.2.1 EWMA-EAD（指数加权移动平均熵异常检测）
- **类**：`EwmaEntropyAnomalyDetectionService`
- **原理**：对流量的端口熵、包大小分布熵进行 EWMA 平滑，计算标准差动态阈值，超阈值即触发异常事件
- **自主实现**：EWMA 系数 `α`、熵计算公式、阈值函数均为团队设计

#### 5.2.2 MDTCE（多维威胁关联引擎）
- **类**：`ThreatCorrelationEngineService`
- **原理**：对同一源 IP 的多类告警事件进行时间窗口聚合，基于告警类型权重矩阵与关联度函数综合评估威胁等级，输出高置信度复合威胁报告
- **自主实现**：权重矩阵、关联规则、置信度计算函数均为团队设计

#### 5.2.3 NBF-RS（网络行为指纹与风险评分）
- **类**：`BehaviorFingerprintService`
- **原理**：为每个 IP 构建多维行为画像（访问端口集合、连接时间分布、流量大小分布、协议偏好），与历史基线比对，输出行为异常分与风险等级（低/中/高/严重）
- **自主实现**：指纹特征向量设计、基线建模方法、相似度评分函数均为团队设计

#### 5.2.4 TPM-PA（时序预测模型驱动预测性告警）
- **类**：`TemporalPredictiveAlertService`
- **原理**：基于历史告警时序数据建立周期性模式模型，预测下一时间窗口告警爆发概率，在实际告警发生前发出预警
- **自主实现**：时序建模方法、概率估计函数、预警触发条件均为团队设计

### 5.3 六类规则威胁检测器（ThreatDetectionService）

以下 6 种威胁检测规则均由团队基于网络安全领域知识自主设计，采用动态阈值机制：

| 检测器 | 检测目标 | 核心规则 |
|-------|---------|---------|
| DDoS 检测器 | 分布式拒绝服务攻击 | 统计时间窗口内同一目标 IP 的并发连接数与流量速率，超出动态阈值触发 |
| PortScan 检测器 | 快速端口扫描 | 统计短时间内源 IP 访问的不同目标端口数量，超阈值认定为扫描行为 |
| SlowPortScan 检测器 | 慢速端口扫描 | 在更长时间窗口内检测低频率端口探测，规避快速扫描检测规则 |
| WormPropagation 检测器 | 蠕虫传播 | 检测一个 IP 在短时间内向多个新目标发起类似连接的扩散模式 |
| Phishing 检测器 | 钓鱼/仿冒流量 | 基于目标端口（80/443）、包大小分布、连接持续时间特征识别可疑钓鱼行为 |
| DataExfiltration 检测器 | 数据泄露 | 检测从内网 IP 向外网发起的大流量、长时连接，结合时间窗口评估数据外传风险 |

## 六、开源协议合规声明

本项目使用的所有开源组件均通过 OSI（Open Source Initiative）认证，各组件协议要求总结如下：

| 协议类型 | 涵盖组件 | 合规要求 |
|---------|---------|---------|
| **Apache-2.0** | Spring Boot 全家桶、ECharts、Vite、Docker | 保留版权声明与协议文本，修改文件需注明；允许商业使用、闭源分发 |
| **MIT** | React、React DOM、Zustand、Axios、@vitejs/plugin-react | 保留 MIT 许可证文本即可；允许商业使用、修改、分发 |
| **BSD-3-Clause** | ECharts-GL | 保留版权、协议、免责声明；不得使用作者名义背书衍生产品 |
| **BSD-2-Clause** | PostgreSQL JDBC Driver | 保留版权与协议声明；无其他限制，允许商业使用 |
| **LGPL-2.1** | Hibernate ORM | 以库方式动态链接使用，无需开源应用代码；若修改 Hibernate 本身则需开放修改部分 |
| **MPL-2.0 / EPL-1.0** | H2 Database | H2 仅在开发/测试阶段使用（`scope: runtime`），不随生产制品发布；MPL-2.0 要求开源对 H2 文件本身的修改，不影响应用代码 |

> **结论**：本项目以"使用库"方式引用上述所有开源组件，未对任何组件源代码进行修改，完全符合各开源协议的合规要求。项目自主研发部分（算法、解析器）不受上述开源协议约束，知识产权归团队所有。
