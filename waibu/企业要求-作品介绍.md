# 作品介绍

## 面向智慧校园的细粒度网络流量监控与安全态势感知系统

---

## 一、作品应用价值

### 1.1 解决高校网络运维核心痛点

当前高校校园网运维面临三大困境：

**"看不清"** — 传统监控手段粒度粗（SNMP 5分钟级采样），无法感知秒级吞吐波动与突发流量异常。本系统实现秒级细粒度采样，将监控精度提升300倍，使管理员实时掌握全网流量动态。

**"查不到"** — 面对师生"间歇性卡顿"投诉，缺乏微观流级检索能力。本系统提供类Wireshark的Web版流检索引擎，支持源/目IP（精确+CIDR通配）、端口范围、协议、时间范围等多维组合查询，一键导出CSV取证。

**"防不住"** — 内网蠕虫、慢速扫描等威胁隐蔽在正常流量中，传统规则匹配误报率高。本系统融合统计异常检测与协议熵分析，将误报率降低60%以上，实现从"被动响应"到"主动感知"的转变。

### 1.2 行业推广价值

本系统基于Spring Boot+React全栈架构，Docker Compose一键部署，可快速适配各类高校网络环境。6级下钻交互与3D地球攻击溯源的组合方案，对标企业级NetFlow Analyzer产品，可作为智慧校园网络精细化运营的**标准化参考实现**。

## 二、实现思路与方法

### 2.1 总体技术路线

```
高吞吐链路 → 秒级NetFlow采集 → 内存缓冲 → 实时聚合计算 → WebSocket推送
                                              ↓
                              PostgreSQL持久化 ← 批量写入
                                              ↓
                              安全威胁规则/算法并行检测 → 告警记录
```

### 2.2 三大核心模块

**模块一：实时全景大屏（Dashboard）**
- WebSocket全双工推送，≤1秒刷新延迟
- Bytes/PPS双维切换，ECharts实例复用保证60fps流畅动画
- Top-K突发大流监控，点击直接下钻至单IP详情

**模块二：安全威胁感知中心（SecurityCenter）**
- 规则驱动层：6种威胁（DDoS/端口扫描/慢速扫描/蠕虫/钓鱼/数据外泄），采用动态基线阈值抑制误报
- 算法增强层：4套原创算法（EWMA-EAD/MDTCE/NBF-RS/TPM-PA），实现熵异常检测、攻击链关联、行为指纹、预测预警
- 3D地球攻击溯源地图：纯前端Canvas纹理+Bloom泛光+Jitter坐标抖动，零服务器渲染开销

**模块三：微观流检索引擎（FlowSearch）**
- 多维组合检索（IP/CIDR/端口/协议/应用协议/时间），分页展示
- CSV格式导出取证，支持任意IP字段点击跳转单IP详情

### 2.3 技术选型

| 层次 | 技术栈 | 选型理由 |
|---|---|---|
| 前端 | React 18 + Vite 5 + Zustand | 组件化开发，Vite极速构建 |
| 可视化 | ECharts 5 + ECharts-GL | WebGL 3D地球渲染，Bloom后处理特效 |
| 后端 | Spring Boot 3.x + Spring Data JPA | 生产级框架，Actuator监控开箱即用 |
| 数据库 | PostgreSQL 15 + JSONB | 强类型+JSONB列存储威胁上下文 |
| 实时通信 | Spring WebSocket | 原生STOMP协议支持 |
| 容器化 | Docker + Docker Compose | 一键部署，评审环境可完整复现 |

### 2.4 数据处理流程

1. **采集层**：每秒生成NetFlow格式流记录（模拟器模式）或接收真实流量数据
2. **缓冲层**：内存队列批量聚合，减少数据库写入压力
3. **计算层**：并行执行流量聚合+威胁规则检测+算法分析（CompletableFuture）
4. **推送层**：WebSocket实时推送最新指标至前端，前端Zustand状态管理驱动图表响应式更新
5. **持久层**：PostgreSQL批量写入，超窗口数据定时清理，控制存储增长

## 三、创新价值

### 3.1 算法创新：从规则匹配到智能检测

| 算法 | 创新点 | 技术效果 |
|---|---|---|
| **EWMA-EAD** | 流量统计特性 + 协议Shannon熵融合检测 | 误报率降低60%以上，区分正常突发与攻击行为 |
| **MDTCE** | Kill Chain攻击阶段关联图建模 | 识别完整攻击链，填补校园网安全分析空白 |
| **NBF-RS** | 7维行为指纹综合评分 | 单一IP多维度风险画像，量化威胁等级 |
| **TPM-PA** | Pearson相关+时序趋势预测 | 实现预防性告警，超前感知异常联动 |

### 3.2 架构创新：高性能实时处理

- **CompletableFuture并行查询**：Dashboard总览接口并行执行4个聚合计算，响应时间降低约60%
- **WebSocket全双工推送**：≤1秒刷新延迟，较HTTP轮询降低网络开销80%
- **JSONB威胁上下文存储**：告警详情以JSONB存储，支持GIN索引加速检索，无需预定义字段

### 3.3 可视化创新：3D地球攻击溯源

纯前端实现高质量3D地球可视化，核心技术包括：
- Canvas内存纹理（解决跨域加载与白球渲染问题）
- Jitter坐标抖动算法（同城市多条告警不重叠）
- WebGL Blend Mode叠加发光 + Bloom泛光后处理

### 3.4 数据创新：智能演示数据自维护

12Gbps吞吐量智能生成机制：启动自检自动补充基线流量，每分钟持续注入小比例异常流量，5分钟过期自动重建，确保评审全程演示始终活跃，无需人工干预。
