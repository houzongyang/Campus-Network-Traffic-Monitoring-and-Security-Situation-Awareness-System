# 第五章 安装及使用

---

## 5.1 环境要求

### 5.1.1 运行环境

系统为Web应用，用户端仅需一台能上网的电脑和一个现代浏览器即可访问使用。

| 项目 | 要求 |
|------|------|
| 浏览器 | Chrome 100+、Firefox 100+、Edge 100+、Safari 15+ |
| 网络 | 能访问公网地址即可 |
| 分辨率 | 推荐1920×1080及以上 |

### 5.1.2 服务器环境（运维人员参考）

如需自行部署系统，服务器需满足以下要求：

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 4核 | 8核 |
| 内存 | 8GB | 16GB |
| 磁盘 | 50GB | 100GB |
| 操作系统 | Windows Server 2019 / Ubuntu 20.04 / CentOS 8 | Windows Server 2022 / Ubuntu 22.04 |
| JDK | OpenJDK 17 | OpenJDK 17 |
| Node.js | 16.x | 18.x |
| 数据库 | PostgreSQL 13 | PostgreSQL 15 |
| Web服务器 | Nginx | Nginx（宝塔面板管理） |

## 5.2 安装部署

### 5.2.1 默认安装（使用已部署系统）

本系统已在云端服务器完成部署，用户可直接使用，无需安装任何软件。

**访问地址：** http://8.146.228.64:3000

打开浏览器，输入上述地址即可进入系统。

### 5.2.2 自行部署（运维人员参考）

如需在其他服务器上部署本系统，按以下步骤操作：

**步骤1：准备环境**
- 安装JDK 17
- 安装Node.js 18
- 安装PostgreSQL 15
- 安装Nginx（可选，推荐使用宝塔面板简化配置）

**步骤2：配置数据库**
- 创建数据库 `network_monitor`
- 配置数据库连接信息（地址、端口、用户名、密码）

**步骤3：启动服务**
- 构建前端：`npm install && npm run build`
- 启动后端：执行 `java -jar network-monitor-backend.jar`
- 配置Nginx反向代理前后端服务

**步骤4：验证部署**
- 访问前端地址，确认页面正常加载
- 检查各功能模块是否可正常使用

## 5.3 主要流程

### 5.3.1 系统首页（全景大屏）

登录系统后，默认进入全景大屏页面。该页面实时展示校园网整体安全态势：

| 区域 | 说明 |
|------|------|
| 顶部统计卡片 | 展示今日流量总数、活跃IP数、告警数量、异常检测数 |
| 中部地图 | 3D地球可视化，展示全球攻击源分布和攻击弧线 |
| 底部图表 | 流量趋势图、协议分布饼图、告警趋势折线图 |

**操作提示：**
- 页面数据每5秒自动刷新
- 点击地图上的攻击弧线，可查看攻击详情
- 点击统计卡片，可跳转至对应详情页面

### 5.3.2 安全中心

查看和管理安全告警：

**查看告警列表**
1. 点击左侧菜单"安全中心"
2. 系统展示所有告警记录，支持分页浏览
3. 可按告警类型、严重级别进行筛选

**告警类型说明**
| 类型 | 说明 |
|------|------|
| 流量异常 | 检测到异常流量模式（突发、低熵等） |
| 行为异常 | 主机行为偏离正常基线 |
| 攻击链 | 检测到多阶段攻击关联序列 |
| 趋势预警 | 基于历史数据预测的潜在风险 |

**告警级别说明**
| 级别 | 颜色标识 | 说明 |
|------|----------|------|
| 高危 | 红色 | 确认的攻击行为，需立即处理 |
| 中危 | 橙色 | 可疑行为，建议关注 |
| 低危 | 黄色 | 轻微异常，可记录观察 |

**确认告警**
1. 点击告警列表中的"确认"按钮
2. 告警状态更新为已确认

### 5.3.3 流检索

检索和分析历史网络流量：

1. 点击左侧菜单"流检索"
2. 输入查询条件：
   - **源IP/目的IP**：输入IP地址精确或模糊匹配
   - **端口**：输入端口号
   - **协议**：选择TCP/UDP/ICMP/HTTP/HTTPS等
   - **时间范围**：选择查询的时间段
3. 点击"查询"按钮查看结果
4. 支持导出CSV格式

**组合查询示例：**
- 查看某IP的所有流量：`源IP = 192.168.1.100`
- 查看HTTP流量：`协议 = HTTP`
- 查看某时段高危端口流量：`目的端口 = 22 OR 3389 AND 时间范围 = 最近1小时`

### 5.3.4 IP画像

对特定IP地址进行深度分析：

1. 在任意页面点击IP地址（如告警列表中的源IP）
2. 系统跳转至IP画像页面，展示该IP的完整分析报告

**画像内容包括：**
| 模块 | 说明 |
|------|------|
| 基本信息 | IP地址、地理位置、活跃时间 |
| 行为分析 | 7维行为指纹向量图 |
| 流量统计 | 流量大小、包数量、会话数统计 |
| 历史活动 | 该IP的历史告警和流量记录 |

### 5.3.5 高级分析

使用创新算法进行深度安全分析：

1. 点击左侧菜单"高级分析"
2. 选择分析算法和参数
3. 点击"分析"查看结果

**可用算法：**

| 算法 | 功能 |
|------|------|
| EWMA-EAD | 自适应异常检测，综合评分识别异常行为 |
| NBF-RS | 行为指纹分析，7维向量刻画主机特征 |
| MDTCE | 攻击链关联，还原完整攻击路径 |
| TPM-PA | 趋势预测预警，提前感知潜在风险 |

**典型使用场景：**
- **日常巡检**：使用EWMA-EAD快速扫描异常
- **事件调查**：使用NBF-RS分析可疑IP行为特征
- **溯源分析**：使用MDTCE还原攻击链
- **主动防御**：使用TPM-PA设置预警规则

## 5.4 常见问题

| 问题 | 解决方案 |
|------|----------|
| 页面无法加载 | 检查网络连接，确认能访问公网 |
| 数据不更新 | 点击页面刷新按钮，或等待自动刷新 |
| 查询无结果 | 调整查询条件，扩大时间范围 |
| IP画像显示"无数据" | 该IP可能无历史活动记录 |
| 3D地球加载缓慢 | 首次加载需下载地图资源，后续会缓存加速 |
